# Bạch Đằng 938 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One new story, Ngô Quyền's victory on the Bạch Đằng in 938, exported as a 16:9 long video and a 9:16 short from the same drawings.

**Architecture:** `bach-dang-video/` is a normal story folder whose `shots-a.js` exposes every scene as a function in `ART`. `bach-dang-shorts/` symlinks the art files and adds a vertical player (a 506.25x900 window on the 1600x900 art) with its own cut list. Root scripts keep taking one folder argument.

**Tech Stack:** Hand-written SVG and CSS keyframes, plain browser JavaScript, Node scripts, Playwright Chromium for recording, ffmpeg, edge-tts.

**Spec:** `.superpowers/specs/2026-11-16-bach-dang-design.md`

## Global Constraints

- Read `CLAUDE.md` first: visual style, shot format, character rig, checking rules and known traps all apply.
- Outlines only through `I(w)`. `shadow()` under anything standing on the ground. Every figure has a motion. Nothing sits unchanged for more than about 2.5 s. Whole figure inside the frame at every camera stop.
- Narration and captions Vietnamese; code, comments, docs and commit messages English. No comments unless they carry a non-obvious why.
- Only Ngô Quyền speaks, paraphrasing the chronicle. No other line is put in a historical figure's mouth, and the narrator states only the seven facts listed in the spec.
- The three older story folders are not edited.
- Never commit or push without asking the user first, each time. Exported mp4 files stay out of git.
- Do not kill any process you did not start. `xuat.sh` needs port 8765 free.

## Review Focus

- A vertical camera stop near the left or right edge of the art: the frame must stay inside 0..1600, never show black.
- A vertical shot of 3 s on a scene whose event (tide, sinking) was written for 20 s: the event must finish or be frozen, never cut mid-way.
- A `hot` word that appears with punctuation or different capitalisation in the line: it must still be coloured.
- A caption chunk wider than the vertical frame (a long Vietnamese word in upper case): it must wrap or shrink, never clip.
- `kiem.js` run on an older 16:9 story: tiles must still be 480x270.
